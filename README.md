# 유진 · 아름 사진 저장소

둘만 쓰는 사진 앨범 페이지입니다. 주소: https://kwonyujin119.github.io/test3/

- 이 저장소에는 **화면(index.html)만** 있습니다. 사진은 여기에 올라가지 않습니다.
- 사진은 PC에서 도는 **별도 앨범 서버**(`server/` 폴더, 설치법은 `server/README.md`)의 사진 폴더에만 저장됩니다. 화면은 `album.sachil47.com`을 먼저 찾고, 없으면 SACHIL:47 서버(app.sachil47.com, 15.8 이상)를 씁니다.
- 들어가기: 접속코드 입력. 코드는 들어간 뒤 ⋯ 메뉴에서 바꿀 수 있습니다.
- 홈 화면에 추가하면 앱처럼 열립니다(PWA).

별도 서버 코드는 이 저장소의 `server/`에, SACHIL 서버 쪽 앨범 API는 kwonyujin119/test 저장소(`server/sachil_server.py`)에 있습니다.
