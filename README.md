# 유진 · 아름 사진 저장소

둘만 쓰는 사진 앨범입니다. PC 한 대(D드라이브 폴더)로 돌고, 도메인이나 다른 서버가 필요 없습니다.

- `server/` : 서버(파이썬 표준 라이브러리만). **설치·사용법은 `server/README.md`**
- `index.html` 등 : 화면. 서버가 직접 보여 줍니다 → 같은 와이파이의 폰에서 `http://<PC주소>:4848`
- 사진은 `server/사진/` 폴더에만 저장되고 GitHub에는 올라가지 않습니다.
- 접속코드로 들어갑니다. 코드는 들어간 뒤 ⋯ 메뉴 또는 `server/set-code.bat`으로 바꿉니다.
